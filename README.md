# m1-modern-js-lab
What is the difference between frontend and backend responsibilities?
Frontended focuses on the UX and UI design, focusing on client-side experience, while Backend focuses on data and the logical side of a business (this includes server management, authorization and security)
Describe the request–response lifecycle.
A client will send in a request, this request is then sent over a network to a server, the serve process the request, the request is sent back over the network to the client with information (We can use google as an example. Someone searches a recipe on google, google send this search over a network to a server, the server obtains the information on the specified recipe and send it back over the network to the client, the client then sees the best websites for this specified recipe)
Why is modular file organization important?
This keeps codes clean, making debugging and testing easier, as well as making prevention easier (prevention of bugs and errors)
